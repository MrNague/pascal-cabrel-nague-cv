01

Minimal Dependency Dataset Library for PyTorch

Abgeschlossen

Bachelorprojekt am DFKI · 04/2026–10/2026

Entwicklung und Benchmarking einer leichtgewichtigen Data-Loading-Library für Parquet-basierte Bilddaten in PyTorch-Trainingsabläufen.

  • Implementierung einer nebenläufigen Pipeline mit Worker-Threads, Sampling, Chunked Staging und Batch-Orchestrierung.
  • Experimentelle Untersuchung mit 1–32 Workern: Durchsatz, Skalierung, Queue-Verhalten und Engpässe der Datenbereitstellung.
  • Vergleich auf Food-101: konkurrenzfähige Werte bei wenigen Workern; bessere Skalierung der PyTorch-Referenz bei höheren Worker-Zahlen.

Stack Python · PyTorch · PyArrow · Parquet · SLURM · Linux

03

ImmoLens — ML-Prototyp zur Immobilienpreisschätzung

In Entwicklung

Eigenständiges Machine-Learning-Projekt · seit 04/2026

Zweisprachige Webanwendung als technischer Prototyp einer ML-gestützten Immobilienpreisschätzung. Die Demo liefert synthetische Schätzwerte für sechs deutsche Städte; eine Validierung mit realen Marktdaten steht noch aus.

  • Random-Forest-Modell mit scikit-learn und Experiment-Tracking mit MLflow.
  • Einbindung in ein Python/FastAPI-Backend mit React/TypeScript-Frontend und geografischer Standortsuche.
  • Technische Qualitätssicherung: 37 Backend-Tests bestanden sowie erfolgreiche Frontend-Build- und Lint-Prüfungen.

Stack Python · scikit-learn · MLflow · FastAPI · pytest · React · TypeScript
