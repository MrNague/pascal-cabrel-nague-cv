01

Minimal Dependency Dataset Library for PyTorch

Abgeschlossen

Bachelorprojekt am DFKI · 04/2026 – 10/2026

Leichtgewichtige Data-Loading-Library für Parquet-basierte Bilddaten, integriert in standardmäßige PyTorch-Trainingsabläufe.

  • Entwicklung einer nebenläufigen Pipeline mit Worker-Threads, Sampling, Chunked Staging und Batch-Orchestrierung.
  • Benchmarks mit 1–32 Workern und Instrumentierung von Durchsatz, Skalierung, Queue-Verhalten und Pipeline-Engpässen.
  • Benchmark-Ergebnis: Peak von 3.245 Samples/s bei 16 Workern im ursprünglichen Benchmark.
  • Food-101-Validierung: konkurrenzfähige Werte bei wenigen Workern, bessere PyTorch-Skalierung bei höheren Worker-Zahlen.

Stack Python · PyTorch · PyArrow · Parquet · SLURM · Linux
